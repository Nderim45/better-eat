# Better Eat

Better Eat is a modern website that helps users find healthier and more convenient food options. The platform is built with a sleek and user-friendly interface that enables users to explore meals, view nutrition information, and get recipe recommendations.

## Table of Contents

- [Features](#features)
- [Demo](#demo)

## Features

- Search and filter recipes by ingredients, dietary preferences, and nutrition.
- View detailed nutritional information for each meal.
- Responsive design for mobile, tablet, and desktop.
- User-friendly, with smooth navigation and clear calls to action.

## Installation

### Prerequisites

- **Node.js** (>= 16.x)
- **npm** or **yarn**
- Optional: **MongoDB** (for the backend if this is a full-stack project)

### Steps

1. Clone the repository:
    ```bash
    git clone https://github.com/Nderim45/better-eat.git
    ```

2. Navigate to the project directory:
    ```bash
    cd better-eat
    ```

3. Install the dependencies:
    ```bash
    npm install
    ```

4. Create a `.env.local` file and add the required environment variables (e.g., API keys, database URLs).

5. Start the development server:
    ```bash
    npm run dev
    ```

6. Open your browser and navigate to `http://localhost:3000`.

## Usage

Once the app is running:

- Explore healthy meal options directly from the homepage.
- Filter meals by ingredients, dietary requirements (e.g., vegan, gluten-free), and more.
- Click on any meal to view its detailed nutritional information and recipe instructions.
- Enjoy a fast, responsive browsing experience on any device.
